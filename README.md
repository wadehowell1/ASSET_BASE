# ASSET_BASE

Public image host for **The Lean Desk** social slides. Nothing else lives here.

Images only — the content, strategy and pricing stay in the private project repo.
Buffer fetches these by URL and cannot log in, which is the entire reason this
repository is public.

## Layout

```
slides/day-01/ig/01.png … 07.png      Instagram + Facebook carousel, 1080×1350
slides/day-01/pin/01.png              Pinterest pin, 1000×1500 (hook only)
slides/day-01/x/01.png                X thread opener, 1600×900 (hook only)
slides/manifest.json                  slide count per day
```

## ASSET_BASE value

```
https://raw.githubusercontent.com/wadehowell1/ASSET_BASE/main/slides
```

A file resolves as `<ASSET_BASE>/day-<NN>/<platform>/<SS>.png`.

Regenerated by `tools/slide-renderer/render.py` in the private repo — edit the copy
there, re-render, and copy the folder across. Never edit a PNG by hand; the next
render overwrites it.
